The controller incorporates the following principal operating features:

    • Automatic repeater PTT control based on qualified RUS activity.
    • Input debounce and qualification to minimize false triggering.
    • Two-second transmitter hang time following qualified RUS loss.
    • Maximum continuous RUS-controlled transmission protection.
    • Automatic 20-second timeout lockout.
    • Three-second post-lockout PTT recovery burst.
    • Automatic CW station identification at approximately 490.2 Hz.
    • Startup identification and two-stage periodic identification scheduling.
    • Deferred identification when receiver activity is present.
